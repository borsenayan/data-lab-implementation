# Hands-On Data Lab Implementation

Practical data analysis lab built with Python and Jupyter.

## What is inside
- `data_lab.ipynb`: environment check, data manipulation, visualization and basic analysis
- `chart_*.png`: charts saved from the notebook

## Setup
```
pip install jupyter pandas numpy matplotlib seaborn
jupyter notebook data_lab.ipynb
```

## Topics covered
- Missing value handling, filtering, groupby and merge
- Bar chart, line chart, histogram and correlation heatmap
- Summary statistics and correlation analysis
